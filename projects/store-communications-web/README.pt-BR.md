# Comunicação com lojas — aplicação web

### Python · FastAPI · JavaScript · SQLite

Aplicação web local que apoia fluxos de comunicação a partir de planilhas, com histórico e exportação.

## O que demonstra

- Separação entre interface web e serviços de backend.
- Importação de planilhas e serviços de modelos de comunicação.
- Armazenamento local de histórico e serviços de exportação.
