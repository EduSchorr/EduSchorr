# Service Invoice PDF Extraction

### Python · PDF · Excel

A document-processing tool for extracting service-invoice information into spreadsheets and separating files that need manual review.

## What it demonstrates

- Structured extraction from PDF documents.
- Spreadsheet output for subsequent analysis.
- Classification of incomplete, scanned or problematic files.
