# Extração de NFS-e em PDF

### Python · PDF · Excel

Ferramenta para extrair informações de notas fiscais de serviço para planilhas e separar arquivos que precisam de revisão manual.

## O que demonstra

- Extração estruturada de documentos PDF.
- Saída em planilha para análise posterior.
- Classificação de arquivos incompletos, escaneados ou com problemas.
