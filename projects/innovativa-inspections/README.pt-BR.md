# Innovativa — protótipo de levantamentos SST

### HTML · CSS · JavaScript · PWA

Protótipo web para levantamentos de segurança e saúde do trabalho, com persistência local e recursos de aplicação web progressiva.

## O que demonstra

- Interface de levantamentos e checklists.
- Persistência local no navegador.
- Manifesto web e recursos de service worker.
