# Analisiin — sistema local de levantamentos

### JavaScript · PHP · SQLite

Edição de teste local de um sistema de levantamentos estruturados, com modelos configuráveis e registros persistidos localmente.

## O que demonstra

- Edição de modelos com perguntas e seções configuráveis.
- Fluxos de formulário com condições e repetições.
- API PHP local e armazenamento SQLite.
