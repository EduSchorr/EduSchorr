# Consolidação e verificação VTEX

### Python · Excel · Browser automation

Fluxo desktop que consolida planilhas de vendas, normaliza identificadores de transação e apoia a verificação de pedidos na VTEX.

## O que demonstra

- Consolidação de planilhas e tratamento de repetições.
- Verificação pelo navegador e registro incremental dos resultados.
- Backups antes de atualizar a planilha consolidada.
