# VTEX Order Verification

### Python · Excel · Browser automation

A desktop workflow that consolidates sales spreadsheets, normalizes transaction identifiers and supports order-status verification in VTEX.

## What it demonstrates

- Spreadsheet consolidation and duplicate handling.
- Browser-assisted verification and incremental result recording.
- Backups before updating the consolidated workbook.
