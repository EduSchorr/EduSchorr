# Adyen Refund Reconciliation

### Python · Desktop UI · Excel

A local application for matching refunded-payment records against an Excel control workbook, with a preview before applying updates.

## What it demonstrates

- Validation of workbook structure and matching identifiers.
- Preview of matching records before updates.
- Export of reconciliation results.
