# Conciliação de reembolsos Adyen

### Python · Desktop UI · Excel

Aplicativo local para cruzar registros de pagamentos reembolsados com uma planilha de controle no Excel, com prévia antes de aplicar alterações.

## O que demonstra

- Validação da estrutura da planilha e dos identificadores.
- Prévia dos registros correspondentes antes da atualização.
- Exportação do resultado da conciliação.
