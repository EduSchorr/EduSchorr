# Portfolio Edition

## English

This directory contains nine documentation-only project presentations. It does not distribute implementation files, runnable builds or real operational datasets.

Descriptions were written specifically for public presentation. No original spreadsheets, PDFs, databases, browser profiles, backup archives, configuration files, credentials, internal addresses, contact lists or operational documents were copied into this catalog.

The public project repositories have also been changed to documentation-only default-branch versions. Their historical commits may still contain previously published code.

## Português (Brasil)

Este diretório contém nove apresentações documentais de projetos. Não distribui arquivos de implementação, versões executáveis ou dados operacionais reais.

As descrições foram escritas especificamente para apresentação pública. Nenhuma planilha, PDF, banco de dados, perfil de navegador, backup, configuração, credencial, endereço interno, lista de contatos ou documento operacional original foi copiado para este catálogo.

Os repositórios públicos de projetos também passaram a versões documentais nas branches principais. Seus commits históricos ainda podem conter código publicado anteriormente.
