# Portfolio Edition

## English

This directory contains nine documentation-only project presentations. It does not distribute implementation files, runnable builds or real operational datasets.

Descriptions were written specifically for public presentation. No original spreadsheets, PDFs, databases, browser profiles, backup archives, configuration files, credentials, internal addresses, contact lists or operational documents were copied into this catalog.

The implementation repositories and their historical commits are now private. This public profile contains only project presentations and portfolio artwork.
