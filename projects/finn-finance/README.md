# FINN — Financial Organization

### React · TypeScript · Vite · Supabase

A financial application project with modules for accounts, transactions, budgets, goals, reporting and receipt processing.

## What it demonstrates

- Modular interface covering financial workflows.
- Dedicated financial-engine and persistence modules.
- Receipt OCR and structured import/export modules.
