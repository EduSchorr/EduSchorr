# FINN — organização financeira

### React · TypeScript · Vite · Supabase

Projeto de aplicação financeira com módulos de contas, transações, orçamentos, metas, relatórios e processamento de comprovantes.

## O que demonstra

- Interface modular para fluxos financeiros.
- Módulos próprios de motor financeiro e persistência.
- Módulos de OCR de comprovantes e importação/exportação estruturada.
